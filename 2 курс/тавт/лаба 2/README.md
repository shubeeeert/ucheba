## Н.У. (строго по заданию)

В работе используются **только** эти переменные:

| Обозн. | Смысл |
|---|---|
| МХ | мой ход |
| ИСТ | история (таблица 4) |
| НР | номер раунда (НР = 0) |
| ХС | ход соперника |
| СХС | следующий ход соперника |
| РЗ | результат |
| КХ | контрход |
| СП | счётчик поражений (СП = 0) |
| СН | счётчик ничьих (СН = 0) |
| С | стратегия (С = 0) |

Начальные установки в схеме: `НР := 0; СП := 0; СН := 0; С := 0; ИСТ := ∅`.
Число раундов `5` и глубина паттерна `2` — константы, отдельных переменных для
них нет.

## Метод

Две стратегии, переключение по счётчикам.

**Стратегия 1 (С = 0), реактивная.** Бот бьёт последний ход соперника:
`КХ = b(ХС)` — таблица 1. Функция `b`: `b(К)=Б`, `b(Н)=К`, `b(Б)=Н`.

**Стратегия 2 (С = 1), проактивная.** Бот ищет в истории повторяющийся
фрагмент (паттерн) и предсказывает следующий ход соперника:

1. взять последние `k` ходов соперника из ИСТ;
2. найти более раннее вхождение такого же фрагмента (сам паттерн не считается);
3. ход, сыгранный сразу после него, — это прогноз `СХС`;
4. `КХ = b(СХС)` — таблица 2.

Поиск идёт от длинного паттерна к короткому: сначала `k = 2` (пары), и только
если пар ещё не повторялось — `k = 1` (отдельные ходы). Это таблица 5.

**Переключение.** Пока `СП + СН < 2` работает стратегия 1. Как только
`СП + СН ≥ 2`, ставится `С := 1`, и переключение необратимо. Если стратегия 2
включена, но паттерн не найден (история короткая или без повторов), бот
играет резервно по таблице 1.

**Таблицы 1 и 2 совпадают** намеренно: в обеих стоит одна функция `b(·)`.
Разница только в аргументе — фактический ход `ХС` или прогноз `СХС`. Это две
разные стратегии с разными источниками данных; совпадение функций — свойство
игры, а не ошибка (подробно в п. 4.3 отчёта).

### Порядок раунда

```
НР := НР + 1
если НР = 1:  МХ := К
вывод МХ  →  сервер возвращает ХС
РЗ := табл. 3 (МХ, ХС)
если РЗ = П:  СП := СП + 1
если РЗ = Н:  СН := СН + 1
ИСТ := ИСТ ∪ {НР, ХС, МХ, РЗ}
если НР = 5:  вывод СП, СН → КОНЕЦ
если СП + СН ≥ 2:  С := 1
если С = 0:  КХ := табл. 1 (ХС)
иначе:       поиск паттерна (табл. 5) → СХС
             если паттерн найден: КХ := табл. 2 (СХС)
             иначе:               КХ := табл. 1 (ХС)
МХ := КХ  →  следующий раунд
```

Схема начинается строго так: **НАЧАЛО → Н.У. → ответ сервера → алгоритм**.
Блок «Паттерн найден?» стоит в конце цикла, перед выбором контрхода.

## Пример работы

Соперник играет **Н, К, Н, К, Н**:

| НР | МХ | ХС | РЗ | СП | СН | С | СХС | КХ |
|---|---|---|---|---|---|---|---|---|
| 1 | К | Н | В | 0 | 0 | 0 | — | К |
| 2 | К | К | Н | 0 | 1 | 0 | — | Б |
| 3 | Б | Н | П | 1 | 1 | 1 | К | Б |
| 4 | Б | К | В | 1 | 1 | 1 | Н | К |
| 5 | К | Н | В | 1 | 1 | 1 | — | — |

Итог: **3 победы, 1 ничья, 1 поражение**. В 3-м раунде сработал уровень
`k = 1` (ход Н уже был, после него — К), в 4-м — уровень `k = 2`
(пара (Н, К) была в раундах 1–2, после неё — Н). Оба прогноза верны.

## Свойства

* **Конечность.** Состояние определяется историей ИСТ: НР — её длина, СП и СН —
  количества П и Н, С вычисляется по истории. В ИСТ не более 5 записей по 3
  варианта хода, значит различных историй не больше
  `1 + 3 + 9 + 27 + 81 + 243 = 364`, то есть у автомата не более 364 состояний.
* **Детерминированность.** Генератора случайных чисел нет: при одной и той же
  игре соперника партия всегда одна и та же.
* **Сложность.** Один раунд — константное число действий; поиск паттерна
  перебирает не более `3² + 3¹ = 12` вариантов. Весь матч — `O(1)` при
  фиксированном числе раундов. Память — несколько десятков бит.
* **Перебор.** Все `3⁵ = 243` последовательности соперника: побед 39,5 %,
  ничьих 21,0 %, поражений 39,5 %. Против равномерно случайного соперника
  перевеса быть не может; против шаблонных (постоянный ход, период 2) баланс
  положительный: до +4…+5 за матч.

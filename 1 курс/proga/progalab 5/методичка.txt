Лабораторная работа 5.1 (Обязательная)
Сортировка больших файлов
Цель работы:
Освоить методы обработки данных, превышающих объем оперативной памяти, путем реализации алгоритмов внешней сортировки. Получить навыки работы с текстовыми и структурированными файлами в языках C++ и Python, провести сравнительный анализ

Задание:
1. Подготовка данных

Выберите предметную область и согласуйте с преподавателем структуру сортируемого файла.

Напишите модуль-генератор, который создаёт текстовый файл data.csv разделитель запятая размером более 1 ГБ.

2. Внешняя сортировка

Реализуйте модули external_sort на языкax С++  и Python, которые сортируют data.csv в файл sorted.txt, используя внешнюю сортировку.

Требования:

Предоставить возможность выбора ключа для сортировки

Объем потребляемой оперативной памяти не должен превышать 10% от размера исходного файла.

После завершения сортировки удалить временные файлы.

Оценить время выполнения этапов разбиения и слияния.

Общее время сортировки файла не должно превышать 10 минут.

Особенности реализации:

Для работы с файлом на С++ используйте модули cstdio или  fstream.

Для работы с файлом на Python используйте менеджеры контекста (with open(...) as f) и библиотеку csv c возможностью чтения блоками.

3. Создание модуля GUI для демонстрации работоспособности реализованных алгоритмов.

Предусмотреть возможность генерации, а затем выбора файла для работы, а также проверки правильности сортировки путем вывода частей файла на экран.

4. Способ интеграции модулей выберите самостоятельно.

Требования к отчету
Отчет должен содержать:

Титульный лист

Цель работы и постановка задачи

Краткое описание алгоритма внешней сортировки

Описание реализации на C++ и Python: основные функции, структуры данных, используемые средства языка

Ссылка на репозиторий

Анализ результатов: объяснение наблюдаемых различий (скорость работы, влияние буферизации, особенности языков)

Выводы

Приложение с листингами кода

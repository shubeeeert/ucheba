ТЕХНИЧЕСКОЕ ЗАДАНИЕ: MVP "Генератор тестовых данных (Test Data Generator)"
1. Пользовательские сценарии:
   - Разработчик настраивает параметры (тип сущности, кол-во строк, наличие NULL).
   - Нажимает "Генерировать" -> наблюдает процесс ETL-симуляции.
   - Получает предпросмотр таблицы и скачивает файл в CSV/JSON.

2. Требования к UI:
   - Левая панель (Sidebar): Select (Тип сущности), Slider (Количество записей 1-1000), Checkbox (Добавить пропуски), Кнопка "Сгенерировать".
   - Центральная область: st.dataframe с предпросмотром (первые 50 строк). Фиксированная высота с вертикальным скроллом.
   - Верхняя панель: Статус-бар, счетчик сгенерированных записей, кнопка "Скачать".
   - Пустое состояние: Подсказка для начала работы.

3. Структура данных:
   - Динамические поля: ID (UUID), Name (Faker), Email (Faker), Created_At (Timestamp), Value_USD (Float), Status_Flag (Categorical).
   - Форматы экспорта: UTF-8, корректное экранирование, валидные типы данных Pandas.

4. Логика симуляции:
   - При нажатии кнопки запускать st.spinner("? Инициализация ETL-конвейера...") на 1.5-2 сек.
   - Данные формируются псевдослучайно через встроенные генераторы.
   - Сохранять результат в st.session_state для избежания повторной генерации при рефреше страницы.
